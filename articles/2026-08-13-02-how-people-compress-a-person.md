「この人、AIをものすごく使っているな」

自分の公開活動を遠くから見れば、たぶん最初はそう見える。

GitHubには投資・企業分析、個人財務、VRChat、旅行、3Dアバター、画像生成、AIエージェント運用など、かなり違う領域のプロジェクトが並んでいる。公開プロフィールにも、実際に使うデータ、作業、記録、判断を、後から検証・再利用できる形へ変えるソフトウェアを作っている、と書いている。

でも、そこから「AIが好きな人」と結論づけると、少し違う。

コードを書くことそのものが好きなのか。
投資なら銘柄そのものが好きなのか。
ゲームなら勝つことそのものが好きなのか。

自分の行動をいくつか並べてみると、別の共通項が見えてきた。

**自分の世界を、理解可能・改善可能・再現可能な状態にしたい。**

この記事では、自分を題材にしながら、**人は他人をどのように圧縮して理解するのか**を考える。

## 遠くから見ると、人間は数語に圧縮される

初対面の人に、投資、AI、製造、VR、ボードゲーム、文章、画像生成、旅行、データベースと順番に話したら、情報量が多すぎる。

人間は理解を諦めて、もっと短いラベルに圧縮する。

> すごく色々やっている変わった人。

ITをあまり知らない人なら、さらに圧縮される。

> パソコンがものすごく得意な人。

慎重な人なら、同じ行動を別の軸で見る。

> 新しいものを高速で試す、ちょっと怖い人。

AIを日常的に使うエンジニアなら、また違う。

> この人はAIそのものが好きなわけではないな。

同じ人間なのに、観測者によって説明が変わる。

これは誰かが間違っているという話ではない。**観測できる情報と、その人が重要だと思う評価軸が違う**からだ。

## 「AIが好き」より「意図が現実になるまでを短くしたい」

AIを大量に使っていると、AI好きに見える。

しかし、自分が欲しいのはAIとの会話そのものではない。

欲しいのは、

**頭の中にある意図が、現実の成果物へ変換されるまでの時間を短くすること**だ。

以前なら、調査して、設計して、コードを書いて、テストして、文章を書いて、公開物を確認するまで、一人の処理能力がボトルネックだった。

AIによって、その制約を部分的に外せる。

だから新しいモデルが登場したこと自体より、

> 昨日まで自分で繰り返していた仕事が、今日は自動で回る

方がずっと重要になる。

この見方をすると、AI利用は目的ではなく手段になる。

## 「コードを書く人」より「世界を矛盾しない状態にしたい人」

GitHubのプロフィールでは、単発デモよりも、出典、データ、処理、成果物、公開状態、失敗履歴を追跡できる仕組みを重視すると書いている。

ここで中心にあるのも、コードそのものではない。

例えば、

- どのデータが正準なのか
- いつ取得した値なのか
- どの処理から成果物が生まれたのか
- 失敗した処理は何だったのか
- 公開されているものと現在のmainは一致しているのか

が曖昧な状態を減らしたい。

そのための道具として、コード、Git、CI、データベース、テストを使う。

人物像としては、

**「コードを書くこと自体より、世界を矛盾しない状態にしたがる人」**

の方が近い。

## 「勝つのが好き」より「上達して勝つのが好き」

これはゲームの記録を見ると分かりやすい。

2024年5月のJoinWars第1回大会の優勝レポートでは、優勝したことだけではなく、大会前に苦手サプライや苦手カードを洗い出し、クロスレビュー表を作って順番に練習したことを書いている。

そして決勝で、まさにそれまで苦手だった構成が出て、その練習が役に立った。

2024年11月の第2回大会でも、苦手部分を意識して練習し、時間制限の厳しいカードについては前日に実戦形式で練習している。

2025年11月の第3回大会では準優勝だったが、負けた理由を具体的に書き、優勝者についても「コンボのパターンを見つけて判断する速度」が練習量に裏打ちされていたと評価している。

この3つを並べると、報酬は単純な勝利だけではない。

**昨日できなかったことができる。**

**負けた理由を理解して、次の能力へ変換する。**

**再現性のある形で勝てる。**

そこに強い喜びがあるように見える。

だから、

**「勝つのが好きな人」より「上達して勝つのが好きな人」**

の方が自分にはしっくりくる。

## 投資でも「銘柄好き」より「市場の歪み好き」

投資も似ている。

銘柄名そのものより、

- なぜこの価格になっているのか
- どの前提が市場に織り込まれているのか
- どこに強制売却や需給の歪みがあるのか
- 弱気シナリオでも価格が成立するのか

を考える方に興味が向く。

株価が上がれば何でも嬉しい、というより、**自分が観測していた歪みが、考えていたメカニズムで解消されたと説明できる方が面白い**。

ここでも、結果より構造を理解したいという性質が出る。

## 表面の行動を、その下の価値へ変換してみる

自分の行動を、もう一段下へ掘ってみるとこうなる。

| 表面に見える行動 | その下にありそうな価値 |
|---|---|
| 大量に作る | **自分の可能性を早い段階で塞ぎたくない** |
| AIを使う | **自分の時間・能力の制約から自由になりたい** |
| 検証する | **本当のことを知りたい** |
| 証拠を残す | **後から事実が曖昧になるのが嫌** |
| 自動化する | **意味のない反復に人生を使いたくない** |
| 投資を分析する | **表面的な物語ではなく構造を理解したい** |
| ゲームを研究する | **上達そのものが楽しい** |
| VR・画像・UIを細かく直す | **「正しい」だけでなく「好きな感じ」を守りたい** |
| 記録する | **経験を消費して終わらせたくない** |
| 他人との練習を記録する | **一人で得た成果だけを成果だとは考えていない** |

全部を一言でまとめるなら、価値観は次の5つに集約できそうだ。

### 自律

自分で決め、自分で試し、自分で修正できる状態を好む。

### 理解

結果だけでなく、「なぜそうなったか」が分かることを好む。

### 再現性

一度うまくいくことより、もう一度できることを重視する。

### 成長

得意なことを誇るより、苦手を特定して改善することに強く反応する。

### 創造と遊び

実用だけではなく、VR、ゲーム、旅行、画像のような「面白いからやる」領域をかなり大切にする。

## 喜びは「成功」より状態遷移にある

この価値観から考えると、強く報酬を感じる瞬間には共通した形がある。

**不可解 → 理解**

**不能 → 可能**

**偶然 → 再現可能**

**手作業 → 自動化**

**弱点 → 克服**

**仮説 → 実証**

**頭の中 → 現実の成果物**

つまり、最終状態だけではなく、**自分が世界の状態を変えたという遷移そのもの**が面白い。

ゲームなら「勝った」より、「前回負けた理由を理解して練習し、今回は勝った」。

AIなら「新モデルを触った」より、「昨日は人間がやっていた仕事が今日は自動で回る」。

投資なら「上がった」より、「観測した歪みが想定した形で解消された」。

## では、何に傷つくのか

ここからは公開記録だけでは確認できない。自己観察を含む仮説として扱う。

自分は、単なる失敗には比較的耐性があるように思う。

失敗は、

1. 原因を調べる
2. 弱点を特定する
3. 修正する
4. 次の検証へ進む

という形に変換できるからだ。

むしろ負荷が大きいのは、**意味を確定できない状態**かもしれない。

- 自分の意図が理解されない
- 理由の分からない状態に置かれる
- 工夫の中身を見ず「AIがやっただけ」と一括処理される
- 自分で変えられるはずのものを、理由なく変えられない
- 好きなものを雑に扱われる

失敗そのものより、**失敗から何も分からない状態**の方が嫌なのではないか。

## 技術では長所でも、人間関係では摩擦になる

この性質は、技術世界ではかなり有効だ。

「正確に理解したい」
「原因を特定したい」
「もっと良くしたい」

は、そのまま改善につながる。

でも、対人関係では同じ言葉が違う意味を持つ。

自分の「正確に理解したい」は、相手には**詰められている**と見えるかもしれない。

自分の「もっと良くできる」は、相手には**今の状態を否定された**と感じられるかもしれない。

自分の「原因を知りたい」は、相手には**そこまで分析されたくない**になるかもしれない。

技術では、曖昧さを減らすことはほぼ無条件に良い。

人間には、曖昧なままにしておきたいことも、説明できなくても受け入れてほしいこともある。

**本人の意図と、相手に与える効果は別物だ。**

## 競争相手から見ると、少し嫌なタイプかもしれない

自分と競争している人から見ると、この学習ループは少し厄介だ。

一度負ける。

理由を記録する。

弱点を分類する。

練習する。

改善方法を残す。

次回へ持ち越す。

すると、相手から見れば、

**「勝つたびに次の対戦相手を強化してしまう」**

ような存在になる。

一回の能力値より、学習率の方が怖い。

これはゲームだけでなく、仕事や投資でも同じだと思う。

## 「何でもできる人」に見えることの副作用

もう一つ、外からの見え方で気になることがある。

大量の成果物や自律的な行動が見えるほど、周囲からは「何でもできる人」に見えやすくなる。

すると、

- 疲れる
- 迷う
- 処理できない
- 傷つく
- 誰かに頼りたい

といった、ごく普通の状態が想像されにくくなる。

「この人なら大丈夫だろう」と扱われやすい。

自律を大切にする人ほど、それに応えられてしまう。

そして応えられるほど、**人から助けられる余地が減る**。

能力が見えやすいことと、人間として理解されやすいことは同じではない。

## 観測距離で人物像は変わる

最後に、自分の見え方を距離で並べてみる。

### 遠景

> ものすごく色々やっている、高出力で変わったAIの人。

### 中景

> 何でも構造化し、検証し、仕組みにする人。

### 近景

> 自分で理解し、自分で選べる状態をかなり大切にする人。

### さらに近景

> 上達するとかなり嬉しい。面白いものが好き。人から学ぶ。好きな対象については細かい。

### 最接近

> **強さや生産性そのものより、自分の世界が理解可能で、自分の意思で動かせて、その中に好きなものや人との面白い経験がちゃんと存在することを大切にしている人。**

## 人を一言で説明すると、たいてい何かが落ちる

「AIの人」も間違いではない。

「プログラマー」も間違いではない。

「投資家」「クリエイター」「ゲーマー」も、部分的には合っている。

でも、その下にある行動原理まで見ると、これらは別々の趣味ではなくなる。

自分の場合は、

**理解 → 自律 → 改善 → 創造 → 記録**

という一つの流れでかなり説明できる。

人を理解するとき、職業や趣味のラベルだけを見ると、その人が「何をしているか」は分かる。

もう一段掘って、

> その人は、どんな状態変化に喜びを感じるのか。
> 何を曖昧なままにしておけないのか。
> 何を守るために、その行動を繰り返しているのか。

まで見ると、「何の人か」ではなく、**「どういう世界を望んでいる人なのか」**が少し見えてくる。
