景気敏感株のPERが2.5倍だったとする。利益がそのまま続くなら魅力的に見える。しかしメモリ、海運、資源のように利益が大きく変動する企業では、分母に置いた利益がどれだけ続くかで倍率の意味が変わる。

低いPERは割安の証拠ではなく、検討の入口である。**その倍率が成立する利益と、好況が終わった後に必要な現金を逆算する。** 2026年11月13日時点のキオクシアを例に、この判断を表計算へ落とす。

## 倍率を残り期間の利益に戻す

PERは株式時価総額を年間純利益で割った値である。倍率を比較する前に、利益の対象年度と株式価値の基準日をそろえる。

キオクシアの当時の終値は9,091円。自己株式を除いた株数を分割後の基準へそろえ、10月末までの新株予約権行使分を反映すると、試算上の株式価値は約14.53兆円となる。[決算短信](https://www2.jpx.co.jp/disc/285A0/140120261030561535.pdf)・[半期報告書](https://ssl4.eir-parts.net/doc/285A/yuho_pdf/S100ZCHE/00.pdf)・[当時の計算記録](https://github.com/KAFKA2306/semiconductor-earnings-model/pull/267)

会社の見通しは2026年4〜12月の累計純利益約3.56兆円までだった。残る1〜3月の利益は、試したい倍率から次の式で逆算できる。

```text
残り期間の必要利益 = 株式価値 ÷ 想定PER − 累計利益見通し
```

| 2027年3月期の仮定 | 1〜3月の必要利益 | 通期利益 | PER |
| --- | ---: | ---: | ---: |
| 直前四半期見通しと同額 | 1.36兆円 | 4.92兆円 | 2.95倍 |
| 当時のIFIS通期予想 | 約1.91兆円 | 5.46兆円 | 2.66倍 |
| PER2.5倍を成立させる | 2.25兆円 | 5.81兆円 | 2.50倍 |

数値は当時の丸めた試算であり、[IFISの予想ページ](https://kabuyoho.jp/reportAnalyst?bcode=285A)は更新され得る。最後の行は市場の確定予測ではなく、任意の倍率を成立させる算術上の条件である。

2.5倍を前提にすると、直前四半期の会社見通しより約0.89兆円多い利益が必要になる。ここで初めて、出荷量、販売単価、製品構成のどの変化が必要額を説明できるかという具体的な問いが生まれる。

## 六つのセルで仮定を動かす

金額の単位を兆円にそろえ、次の六つのセルを使う。

| セル | 入力・式 |
| --- | --- |
| B2 株式価値 | 14.53 |
| B3 想定PER | 2.5 |
| B4 累計利益見通し | 3.56 |
| B5 残り期間の必要利益 | `=B2/B3-B4` |
| B6 直前四半期見通し | 1.36 |
| B7 必要増益率 | `=B5/B6-1` |

B7を百分率にすると約65.6%になる。B3だけを3に変えるとB5は約1.283兆円、B7は約マイナス5.6%になる。少しの倍率差で必要な増益の方向まで変わる。六セルの計算は任意の倍率に対する必要利益を明らかにするもので、適正倍率を決定するものではない。

株式分割前後の価格と株数を混ぜたり、異なる決算期の利益を使ったりすれば、この逆算は無意味になる。増資や会社見通しの更新があれば同じセルを更新する。赤字や大きな一時損益がある企業では、利益倍率より現金の発生能力を検討する。

## 好況が終わった後に必要な現金

高い会計利益が続いても、その全額が株主に帰属する現金になるわけではない。キオクシアの2026年4〜9月の営業キャッシュフローから有形・無形の設備投資を引いた額は約2.24兆円だった。同じ9月末の未払法人所得税は約0.97兆円である。100%還元方針も、設備投資等を賄ってネットキャッシュを維持した後の中長期の余剰資金を対象としている。[決算短信](https://www2.jpx.co.jp/disc/285A0/140120261030561535.pdf)・[株主還元方針](https://www2.jpx.co.jp/disc/285A0/140120261030561562.pdf)

そこで好況中の株主帰属キャッシュフローを四半期5,750億円、年割引率10%、平常化後の成長率0%と仮定する。好況期の現在価値を株式価値から引き、残りを平常化後の現金で説明する。[当時のモデルと計算式](https://github.com/KAFKA2306/semiconductor-earnings-model/blob/c9f28ebe283a44b6d54b57c881f30df074a5cb17/docs/equity-brief.md)による試算は次のようになる。

| 好況の残存期間 | 平常化後に必要な年間CF |
| --- | ---: |
| 0四半期 | 約1.45兆円 |
| 4四半期 | 約1.36兆円 |
| 8四半期 | 約1.26兆円 |
| 12四半期 | 約1.14兆円 |

この設定では好況が一年続いても、平常化後の必要額は約900億円しか下がらない。好況期の現金や割引率を変えれば結果も変わるが、重要なのは現在の利益と好況後の稼ぐ力を区別できる点にある。

別の景気敏感株を調べるときも、まず表計算で残り期間の利益を求め、その数字を直前の会社見通しと比べる。次いで好況期間と平常時の現金を変数として動かす。価格が安いと判断するために必要な前提を明確にすれば、次の決算で何を確かめるべきかが分かる。
