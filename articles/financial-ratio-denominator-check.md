**百分率が同じでも、分母が違えば同じ数字ではない。**

Nebiusの2026年7〜9月期資料で「顧客前払いが設備投資の100％超を賄う」とあったのは、**新規の一定の契約にひもづく設備投資**の話だ。2027年の**全社設備投資400億〜450億ドル**については、前払いと借入を合わせて75〜85％を賄う計画だった。[SEC提出の株主書簡](https://www.sec.gov/Archives/edgar/data/1513845/000110465926126008/tm2629571d1_ex99-2.htm)

100という値を維持して分母だけを「2027年全社設備投資」へ入れ替えた反例では、数値だけの照合は通り、原典の定義を照合する検査は落ちた。そこでの汎用規律は **「比率を使う前に、分子・分母・期間・実績と計画の別を固定せよ」**。数字の検査だけでは、別の問いへのすり替えを止められない。

## 同じ設備投資でも、答えている問いが違う

| 開示値 | 分子 | 分母 | 何が分かるか |
| --- | --- | --- | --- |
| 100％超 | 対象契約の顧客前払い | 2026年7〜9月期に結んだ期間1年以上の対象契約にひもづく設備投資 | 新規案件を取ったときの資金条件 |
| 75〜85％ | 顧客前払いと、投資適格の顧客との契約を裏付けとする借入 | 2027年の全社設備投資 | 会社が計画する資金調達の組み合わせで賄える割合 |

全社設備投資の計画は400億〜450億ドルです。投資額とカバー率の両端を独立に組み合わせると、上記二つの資金源以外で賄う額は60億〜112.5億ドルになります。手元資金や他の調達を充てる前の単純試算です。100％超を全社計画に移すと、この金額を見落とします。 [Nebiusの株主書簡（SEC提出資料）](https://www.sec.gov/Archives/edgar/data/1513845/000110465926126008/tm2629571d1_ex99-2.htm)

2026年7〜9月期の連結営業キャッシュフローはマイナス2.730億ドルで、有形固定資産・無形資産の購入額は73.004億ドルでした。差し引きはマイナス75.734億ドルです。契約条件の改善を「当四半期に設備購入後の現金が残った」と読み替えると、ここでも判断が変わります。 [Nebiusの決算発表（SEC提出資料）](https://www.sec.gov/Archives/edgar/data/1513845/000110465926126008/tm2629571d1_ex99-1.htm)

## 全社設備投資の不足分を実際に計算する

2027年の全社設備投資計画400億〜450億ドルとカバー率75〜85%から、ほかの資金源で補う必要がある額の**条件付き範囲**を求める。単位は億ドル。これは会社が不足額を公表したという意味ではない。

```python
min_capex, max_capex = 400, 450
min_cover, max_cover = 0.75, 0.85
least = min_capex * (1 - max_cover)
most = max_capex * (1 - min_cover)
print(round(least, 2), round(most, 2))
# 60.0 112.5
```

最小不足額は`400×15%=60`、最大不足額は`450×25%=112.5`。一方、対象契約の「前払い100％超」は**別の契約群・別の分母**なので、この全社の計算へ直接入れない。同じ数値でも、どの年度・どの資金源・何を分母にしたかが違えば集計対象を分ける。[NebiusのSEC提出資料](https://www.sec.gov/Archives/edgar/data/1513845/000110465926126008/tm2629571d1_ex99-2.htm)

## 数字を合わせたまま、分母だけを壊す

手元の検証では、開示値に比較記号・対象期間・分子・分母・実績か計画かを持たせました。以下はその検査を縮めた例です。原典から抽出済みの一行を入力とし、同じ100でも分母の違う候補を落とします。

```python
from dataclasses import dataclass, replace


@dataclass(frozen=True)
class Ratio:
    comparison: str
    percent: int
    period: str
    numerator: str
    denominator: str
    kind: str


expected = Ratio(
    ">", 100, "2026Q3",
    "対象契約の顧客前払い",
    "期間1年以上の新規対象契約にひもづく設備投資",
    "実績",
)
candidate = replace(expected, denominator="2027年の全社設備投資")

assert candidate.percent == expected.percent  # 数値照合は通る
assert candidate != expected                 # 原典と照合すると不一致
```

実際の検証では、Nebiusの2四半期、CoreWeaveの1四半期、Nebiusの決算提出直前の4ケースを使いました。提出直前のケースでは、後から公開された数値が混ざらないことも確認しました。分母を差し替えた候補は棄却され、同じ原典で再実行した構造化出力はバイト単位で一致しました。この結果が示すのは、登録した開示と取り違えを再現できたことです。別企業や別様式への適用では、先にその会社の定義を一次資料で確かめます。 [Nebius 2026年4〜6月期決算](https://www.sec.gov/Archives/edgar/data/1513845/000110465926094568/tm2622968d1_ex99-1.htm) · [CoreWeave 2026年7〜9月期決算](https://www.sec.gov/Archives/edgar/data/1769628/000176962826000461/coreweave3q26earningspress.htm)

次の決算では、決算書や株主向け書簡の該当段落と、検査したい集計表の一行を並べます。まず原典から比較記号・分子・分母・期間と、実績か計画かを写します。次に、その数字で答えたい問いを書きます。最後に、取り違えたときに答えが変わる項目を一つ選び、値を維持したまま意図的に差し替えます。元の一行が通って差し替えた一行が落ちるか確かめ、両方通るなら、その項目を判定条件に加えます。


## 他分野で使える条件と撤回条件

広告の転換率、設備稼働率、売上成長率も、分母や対象期間を替えると改善を装える。これは**応用仮説**であり、各業界で同じ不正を実測したという話ではない。

原典が比率の定義・対象・時点を共通に保証し、計算で同じ結果を再現できるなら、その後の自動比較は可能になる。定義が変わったときには比較を止める。**計算が正しいことと、同じ問いに答えたことは別に検査する。**
