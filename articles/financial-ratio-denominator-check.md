「顧客の前払いで設備投資の100%超を賄える」という説明を見たとき、会社全体の設備投資に追加資金が不要だと判断してよいだろうか。

Nebiusの2026年7〜9月期の開示では、その比率は一定の新規契約にひもづく投資を対象としていた。翌年の全社投資計画には別の比率が示されている。数字を一字も変えなくても、分母を取り違えれば別の結論になる。

## 契約の資金条件と全社の資金需要を区別する

[SEC提出の株主書簡](https://www.sec.gov/Archives/edgar/data/1513845/000110465926126008/tm2629571d1_ex99-2.htm)にある二つの比率を並べる。

| 開示値 | 分子 | 分母 |
| --- | --- | --- |
| 100%超 | 対象契約の顧客前払い | 2026年7〜9月期に結んだ期間1年以上の対象契約にひもづく設備投資 |
| 75〜85% | 顧客前払いと投資適格顧客の契約を裏付けとする借入 | 2027年の全社設備投資計画 |

全社設備投資の計画は400億〜450億ドルである。投資額とカバー率の両端を独立に組み合わせると、上記の二つの資金源以外で賄う額は次のようになる。

```python
print(400 * (1 - 0.85), 450 * (1 - 0.75))
# 約60億ドル、112.5億ドル
```

これは会社が公表した資金不足額ではない。手元資金や他の調達を充てる前の条件付き試算である。契約単位の100%超を全社へ転用すると、そもそもこの必要額を考えなくなる。

さらに[同四半期の決算発表](https://www.sec.gov/Archives/edgar/data/1513845/000110465926126008/tm2629571d1_ex99-1.htm)によると連結営業キャッシュフローはマイナス2.730億ドル、有形固定資産・無形資産の購入額は73.004億ドルだった。差し引きはマイナス75.734億ドルである。契約条件、将来の資金調達計画、当期の現金収支はそれぞれ異なる問いに答えている。

## 数値を維持したまま、意味を変える

原資料との照合で、値だけを確認する方法には欠陥がある。実際に開示の分母を意図的に差し替えた検査では、数値の一致は維持されたが、定義の照合では不一致になった。次はその仕組みを縮めた例である。

```python
from dataclasses import dataclass, replace

@dataclass(frozen=True)
class Ratio:
    comparison: str
    percent: int
    period: str
    numerator: str
    denominator: str
    kind: str

expected = Ratio(
    ">", 100, "2026Q3",
    "対象契約の顧客前払い",
    "期間1年以上の新規対象契約にひもづく設備投資",
    "実績",
)
candidate = replace(expected, denominator="2027年の全社設備投資")

assert candidate.percent == expected.percent
assert candidate != expected
```

元の検査ではNebiusの2四半期、CoreWeaveの1四半期、Nebiusの決算提出直前の計4ケースを使った。提出直前のケースでは後日公開された値が混ざらないことを確認し、同じ原典での構造化出力はバイト単位で一致した。対象は登録済みの開示であり、あらゆる企業の文書を自動で正しく解釈できることまでは示していない。[Nebius前四半期の開示](https://www.sec.gov/Archives/edgar/data/1513845/000110465926094568/tm2622968d1_ex99-1.htm)・[CoreWeaveの開示](https://www.sec.gov/Archives/edgar/data/1769628/000176962826000461/coreweave3q26earningspress.htm)

## 比率を引用するときに残す六つの項目

決算書の一行と集計表の一行を並べ、次を埋める。

| 項目 | 何を残すか |
| --- | --- |
| 値 | 比較記号を含む数値 |
| 分子 | 何を数えたか |
| 分母 | 何を全体としたか |
| 期間 | いつの値か |
| 種別 | 実績・予想・計画の別 |
| 出典 | 原典の該当箇所 |

広告の転換率や設備稼働率にも同じ考え方を適用できる。異なる定義が必要なら別の比率として管理する。定義が共通で計算も再現できるときは、そのまま自動比較へ進める。

数字が一致したかだけでなく、数字が同じ問いに答えているかを確かめる。
