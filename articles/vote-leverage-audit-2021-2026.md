> 検証基準日：2026年8月15日
>
> この記事では、2024年10月27日の衆議院選挙から次の衆議院選挙が行われた2026年2月8日までの469日間を対象にする。政党の「成果」発表だけでは判定せず、国会、財務省、首相官邸などの記録で、実際に予算・法律・税制が変わったかまで確認する。

2024年10月27日、自民党は191議席、公明党との連立与党は215議席まで減った。

衆議院465議席の過半数は233。政府側は18議席足りなくなった。

その469日後の2026年2月8日、自民党は316議席、日本維新の会を含む連立与党は352議席を獲得した。

つまり日本には、与党だけでは衆議院の過半数を作れない期間が469日あった。

では、その469日で何が変わったのか。

2024年に与党を過半数割れさせた一票は、実際に法律や予算を動かしたのか。それとも政治ニュースが増えただけだったのか。

調べると、答えは単純な「成功」「失敗」ではなかった。

政治資金制度は変わった。

政府予算は修正された。

所得税も変わった。

高校授業料支援も増えた。

高額療養費の負担増は止まった。

ガソリンの暫定税率も最終的に廃止された。

一方で、物価高に対して補助金で価格を直接下げる政策は残った。マクロ経済政策まで一方向に転換したわけではない。

この記事では「野党が勝ったか」ではなく、2024年の投票で生まれた少数与党が、何を変え、何を変えられなかったかを数字で答え合わせする。

## 2024年10月27日、自公は過半数233まで18議席足りなくなった

第50回衆議院議員総選挙で、自民党は191議席だった。自民・公明の連立与党は215議席となり、過半数233を下回った。

国民民主党は選挙前7議席から28議席へ増えた。比例代表票は2021年の259万票から2024年の617万票へ2.4倍になった。

この28議席は、単に「野党が28人いる」という意味ではなかった。

政府側は過半数まで18議席足りない。28議席を持つ党と合意できれば、衆議院の多数を作れる。

これが2024年選挙で生まれた最も重要な変化だった。

## 2024年11月11日、首相を決める投票すら1回では決まらなかった

選挙から15日後の2024年11月11日、衆議院で内閣総理大臣指名選挙が行われた。

1回目は石破茂221票、野田佳彦151票、馬場伸幸38票、玉木雄一郎28票などに分かれ、誰も過半数233に届かなかった。

そのため石破氏と野田氏による決選投票になった。

決選投票は石破221票、野田160票、無効84票だった。

30年ぶりの首相指名決選投票である。

この数字は、2024年の有権者が「別の一党へ政権を丸ごと渡した」というより、国会を複数勢力へ分散させたことをよく表している。

## 2024年12月12日、選挙から46日で政府の補正予算が修正された

2024年12月12日、衆議院は令和6年度一般会計補正予算を修正議決した。

修正では、一般予備費のうち1,000億円を能登半島地震と同年9月の豪雨からの復旧・復興に使うことを予算総則に明記した。

補正予算そのものの総額を大きく組み替えたわけではない。しかし、政府が提出した予算案が国会審議で修正され、その修正後の予算が2024年12月17日に成立したという事実は重要である。

「政府案は与党だけでそのまま通る」という状態ではなくなったことが、選挙から46日で予算に表れた。

## 2024年12月24日、政策活動費の禁止法が成立した

2024年衆院選では、自民党派閥の政治資金問題が大きな争点になった。

選挙から58日後の2024年12月24日、参議院本会議は政策活動費を禁止する政治資金規正法改正案を全会一致で可決した。

法律は、政党が政治家個人へ資金を渡し切り、最終的な使途を明らかにしない形の支出を禁止する。施行日は2026年1月1日である。

これは選挙結果だけが原因だと証明できるものではない。政治資金問題は選挙前から国会で議論されていた。

それでも、2024年選挙後の少数国会で、複数党提出の法案が成立し、制度そのものが変更されたことは確認できる。

評価すると、政治資金の透明性については「議論が増えた」ではなく「法律が変わった」まで到達した。

一方、この法律だけで企業・団体献金を含む政治資金問題の全てが解決したわけではない。

## 2024年12月11日の3党合意は、2025年に6,210億円の所得税減収を伴う修正へ進んだ

2024年11月20日から、自民党、公明党、国民民主党は税制協議を始めた。

2024年12月11日、3党幹事長は「103万円の壁」を国民民主党が主張する178万円を目指して引き上げることと、ガソリン暫定税率を廃止することに合意した。

ただし、2025年に178万円がそのまま実現したわけではない。

協議は完全合意に至らない局面もあり、2025年度税制改正は国会でさらに修正された。

2025年3月4日の衆議院修正では基礎控除の特例が追加され、財務省はこの修正による2025年度の所得税減収を約6,210億円と見積もっている。

したがって評価は「国民民主党の178万円案がそのまま成立した」ではない。

「28議席を得たことで要求が正式な与党協議に入り、政府提出法案が国会で修正され、6,210億円規模の税収変更まで進んだ」が正確である。

なお、課税最低限を178万円まで引き上げる措置は、後の2025年12月26日に閣議決定された令和8年度税制改正大綱で改めて盛り込まれた。

## 2025年3月4日、高校授業料支援で1,064億円が追加された

2025年2月25日、自民、公明、日本維新の会は教育無償化などについて合意した。

その後の2025年3月4日の衆議院予算修正で、高校無償化関係の予算は1,064億円増額された。

財務省によると、文教及び科学振興費は修正前の5兆5,496億円から5兆6,560億円となった。

これは維新の議席が政策交渉へ変換された具体例である。

ただし「1,064億円増えた」だけで政策の質は判定できない。

家計の教育費を下げる効果は直接的である。一方、所得制限を外して広く支援することが、限られた財源を使う方法として最適だったか、教育成果をどれだけ改善したかは別の評価が必要になる。

実現力と政策の良し悪しは分けて見る必要がある。

## 2025年3月31日、高額療養費の負担増は延期され、予算は史上初めて衆参双方で修正された

2025年度予算は2025年3月4日に衆議院で修正された後、3月31日に参議院でも修正された。

財務省は、衆議院と参議院の双方で予算修正が行われたのは史上初と説明している。

参議院で大きな争点になったのが高額療養費制度だった。

政府が予定していた見直しは全体について実施を見合わせ、2025年秋までに改めて検討することになった。予算上は、衆議院修正で55億円、参議院修正でさらに105億円が増額された。

患者の短期的な自己負担増を止めたという意味では明確な効果がある。

一方、高額医療を誰がどこまで負担するかという社会保障財政の長期問題を解決したわけではない。

ここでも「政府案を止めたこと」と「持続可能な制度を作ったこと」は別である。

## 2025年12月、ガソリン暫定税率は6党合意を経て廃止された

ガソリン暫定税率の廃止は、2024年12月11日の自民・公明・国民民主3党合意だけでは実現しなかった。

その後も協議が続き、2025年12月には自民、維新、立憲、国民、公明、共産の6党合意に基づく法律が成立し、ガソリン・軽油引取税の暫定税率廃止まで進んだ。

2024年の要求が、1年かけて制度変更まで到達した例として見ることができる。

ただし、これも「マクロで最適な物価高対策だった」と自動的に評価するべきではない。

税率を恒久的に下げれば家計負担は下がるが、税収も減り、燃料価格を通じた省エネの動機にも影響する。代替財源やエネルギー政策まで含めて初めて政策全体を評価できる。

出典：

- 首相官邸「高市内閣総理大臣記者会見」：2025年12月17日

## それでも、2024年の投票は物価高政策そのものを一本化しなかった

ここが、この469日を「全部成功」と評価できない理由である。

2024年選挙後、税制や教育、政治資金制度は実際に変わった。

しかし、物価高への政策手段は一方向には収束しなかった。

減税も行う。

給付も行う。

電気・ガス料金補助も行う。

ガソリン補助も行う。

2025年度補正予算では「生活の安全保障・物価高への対応」に8兆9,041億円が計上され、その中には電気・ガス代支援や各種給付も含まれた。

つまり2024年の有権者は「価格補助をやめて、マクロ的により効率的な政策へ転換せよ」という一つの明確な政策を選んだわけではない。

少数与党になったことで各党の要求が政府案へ入りやすくなった結果、政策の種類はむしろ増えた。

短期的に家計を助ける施策と、長期的な成長率・供給力・財政持続性を改善する施策は別物である。

今後の評価では「実施したか」だけでなく、同じ弱点を持つ短期施策を何度も繰り返していないかまで見る必要がある。

## 2026年2月8日、自民316議席で少数与党の469日間は終わった

2026年2月8日の第51回衆議院議員総選挙で、自民党は小選挙区249、比例67、合計316議席を獲得した。

国民民主の28議席や他の野党議席を借りなくても、衆議院の通常の多数を作れる。

したがって、2024年に存在した「野党が賛成しなければ政府案を通しにくい」という交渉環境は、2026年2月8日に大きく後退した。

## 2024年の投票は、目的によって評価が変わる

2024年10月27日の投票を一言で「成功」「失敗」と評価すると雑になる。

目的別なら、かなり明確に答えられる。

| 2024年に期待したこと | 2026年から見た答え合わせ |
|---|---|
| 自公だけで政策を決められないようにする | 達成。215議席で過半数233を18下回った |
| 野党との政策協議を増やす | 達成。税制、教育、予算などで複数の党間協議が発生 |
| 政府提出の予算を実際に変える | 達成。2024年度補正、2025年度当初予算が国会修正された |
| 政治資金制度を変える | 一部達成。政策活動費禁止などが成立。ただし政治資金問題全体が解決したわけではない |
| 手取りを増やす | 一部達成。2025年に6,210億円の所得税減収を伴う修正。178万円はその後の2026年度税制改正へ続いた |
| 教育費を下げる | 一部達成。高校無償化関係を1,064億円増額 |
| 医療費負担増を止める | 達成。2025年3月31日に高額療養費見直しを延期 |
| ガソリン暫定税率を廃止する | 達成。2025年12月に法律成立 |
| 政権交代する | 未達。石破政権が継続した |
| 物価高対策を一つの合理的な設計へ整理する | 未達。減税、給付、価格補助が併存した |
| マクロで効果の弱い短期施策を繰り返さない | 未達。価格補助などの短期策はその後も繰り返された |

この表から見えるのは、2024年の投票が「効かなかった」のではないことである。

かなり多くの政策を動かした。

ただし、動かした政策がすべて良い政策だったわけでもない。

政治的な実現力と、政策そのものの質は別に監査しなければならない。

## 次の選挙では「公約」より5つの記録を見る

2024年を答え合わせすると、次の投票で見るべきものも変わる。

1. 自分が変えたい政策を具体的に一つ決める。
2. その政策について各党が過去に何を要求したか、日付付きで確認する。
3. その党の議席が、政府が多数を作るため本当に必要な票になるかを見る。
4. 過去にその票を、合意だけでなく予算・法律・税制の変更まで変換した記録があるか確認する。
5. 実現した政策が、短期の家計負担だけでなく、成長率、供給力、実質所得、財政、インフレなどマクロの目的にも効いたかを別に評価する。

「公約を守ったから良い」では足りない。

効果の弱い政策を公約通り何度も実施することもできるからである。

## 結論：2024年に変わったのは「政策」だけでなく「政策を決める力関係」だった

2024年10月27日の投票で最も大きく変わったのは、特定の一政策ではなかった。

政府が野党を無視して衆議院の過半数を作れない、という力関係だった。

その結果、2024年12月には補正予算が修正され、政治資金制度が変わった。

2025年には所得税、高校授業料支援、高額療養費、当初予算が修正された。

2025年12月にはガソリン暫定税率廃止まで到達した。

だから「野党に投票しても何も変わらなかった」は記録と合わない。

一方で「少数与党にすれば政策が良くなる」も自動的には成立しない。

少数与党は、政策を競争させる装置にはなった。しかし、短期給付、価格補助、減税が重なり、マクロで何を改善したいのかが曖昧な政策も残った。

2024年の教訓は、野党か与党かだけで投票先を決めることではない。

自分が何を変えたいのか。その党は過去に何を要求したのか。その議席は交渉に必要なのか。実際に制度へ変えたことがあるのか。そして、その制度は本当に社会全体を良くしたのか。

2024年の469日間は、その5つを別々に見る必要があることを示した。
