# かふか・Kafstylerの独自視点：棚卸しと聖典の選定

2026-11-28。対象は現行KafstylerのMISSION・AGENTS・著者別原典・関連Skills、articlesの既存原稿の主張、本人が明示した価値判断。公開済み記事と未公開原稿を含む。原稿本文の主張は著者が実証した一般法則と同一ではない。個別設定・個人情報・非公開の具体的事情は収録しない。

独自性は世界初を意味しない。既存知見のうち、本人が何を優先し、何を拒否し、どの判断に使うかを整理した。観測に反する場合は採用原理を修正する。現行規約と矛盾する過去の手順は歴史的事例として扱い、実行義務を復活させない。

## 選定基準

- 本人またはKafstylerの明示方針・著者原稿に根拠を持つ。
- 別分野でも具体的な行動・採否を変える。
- 独立した意味を持ち、重複する視点を統合できる。
- 反例や適用外を説明できる。製品名・一時的な設定や個別事情に依存しない。
- 記事の主張を強制せず、事実と反例を優先する。

右欄は[厳選した聖典](../pipeline/contracts/article.md)の対応番号。複数番号は横断的な応用。個別は原則に昇格させない。この棚卸しは選定理由の参照資料であり、定期プロンプトへ毎回全文投入しない。
